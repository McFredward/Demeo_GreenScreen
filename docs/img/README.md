# README images

`demeo-mixed-reality.jpg` is the maintainer's screenshot, supplied as
`20261021140727_1.jpg` and copied without modification.

The Steam Frame logos are Valve artwork, reused from
[GloomhavenVR](https://github.com/McFredward/GloomhavenVR/tree/main/docs/img).
The dark-theme variant uses white lettering; the original shapes and blue are
unchanged. The mark identifies the headset used for Steam Link passthrough.
